SKey — Bộ gõ Tiếng Việt tốt nhất cho Linux

Giải pháp gõ tiếng Việt không gạch chân cho Linux chuẩn Fcitx5 — Phản hồi tức thì, mượt mà như bộ gõ native.

Gõ tiếng Việt không gạch chân cho Linux

Mặc định gõ trực tiếp không gạch chân (Non-preedit) qua Surrounding Text. Ký tự xuất hiện ngay lập tức, mang lại cảm giác gõ native 100%.

Gõ tự do kiểu UniKey

Double-letter transform (dd→đ, oo→ô) mọi vị trí. Đổi dấu liên tục, viết tắt (vcđ, nđm) thoải mái.

Auto Mode thông minh

Tự động chọn Surrounding Text hoặc Uinput dựa trên ứng dụng. Nhận diện terminal, Electron, Chromium — không cần cấu hình.

Support nhiều nền tảng

Hoạt động trên cả X11 và Wayland. Hỗ trợ KDE Plasma, GNOME, Hyprland, Sway, Niri. Cài đặt trên Ubuntu, Fedora, Arch.

Nhẹ và nhanh

Engine bamboo-core (Rust) qua FFI. Chạy monolithic không daemon. Adaptive delay cho Uinput — không mất chữ.

Cấu hình & cập nhật dễ dàng

Settings GUI (Qt6) trực quan. Cập nhật phiên bản mới chỉ 2 click trong GUI, hoặc qua apt / dnf / pacman.

Cài đặt — Ubuntu / Debian

Hướng dẫn này áp dụng cho Ubuntu (bao gồm cả GNOME, Kubuntu, Xubuntu, Lubuntu), Linux Mint, Zorin OS, Pop!_OS, elementary OS, Debian, và tất cả các bản phân phối dựa trên Debian.

Cách 1: APT Repository (khuyến nghị)

Thêm repository chính thức để nhận cập nhật tự động qua apt update:

Bước 1: Thêm repository SKey:

Terminal 
curl -fsSL https://collyn.github.io/skey/install.sh | sudo bash

Bước 2: Cài đặt SKey:

Terminal 
sudo apt install fcitx5-skey

Sau khi cài, SKey tự động chạy skey-setup để cấu hình mọi thứ. Bộ gõ sẵn sàng sử dụng — chuyển đổi bằng Ctrl+Space.

Lưu ý cho Wayland
Sau khi cài, bạn cần chọn Virtual Keyboard là Fcitx 5 trong System Settings. Xem chi tiết ở phần Cấu hình Fcitx5.

Cách 2: Từ file .deb

Nếu không muốn thêm repository, bạn có thể tải trực tiếp file .deb từ GitHub Releases:

Terminal 
sudo dpkg -i fcitx5-skey_*.deb
sudo apt install -f        # cài dependencies nếu thiếu
skey-setup                 # cấu hình fcitx5
Mẹo
Cách 1 (APT Repository) được khuyến nghị vì bạn sẽ nhận cập nhật tự động mỗi khi chạy sudo apt update && sudo apt upgrade.

Build từ source

Nếu bạn muốn tự biên dịch SKey từ mã nguồn, hãy làm theo các bước dưới đây.

1. Cài đặt dependencies

Chọn hệ điều hành của bạn:

Bắt buộc — toolchain, fcitx5 headers, dbus:

Terminal 
sudo apt install build-essential cmake extra-cmake-modules pkg-config gettext \
  libfcitx5core-dev libfcitx5utils-dev fcitx5 \
  libdbus-1-dev librsvg2-bin curl

Tuỳ chọn — Settings GUI (Qt6):

Terminal 
sudo apt install qt6-base-dev
Rust Toolchain
Trên Ubuntu < 24.04, gói rustc/cargo từ apt quá cũ. Cài qua rustup:
Terminal 
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain stable
source "$HOME/.cargo/env"
Trên Ubuntu ≥ 24.04, có thể dùng: sudo apt install rustc cargo

Bắt buộc:

Terminal 
sudo dnf install cmake extra-cmake-modules pkgconf-pkg-config gettext \
  fcitx5-devel fcitx5 dbus-devel \
  rust cargo gcc-c++ make

Tuỳ chọn — Settings GUI (Qt6) + PNG icon:

Terminal 
sudo dnf install qt6-qtbase-devel librsvg2-tools

Bắt buộc:

Terminal 
sudo pacman -S base-devel cmake extra-cmake-modules pkgconf gettext \
  fcitx5 dbus \
  rust cargo

Tuỳ chọn — Settings GUI (Qt6) + PNG icon:

Terminal 
sudo pacman -S qt6-base librsvg

Bắt buộc:

Terminal 
sudo zypper install cmake extra-cmake-modules pkgconf gettext \
  fcitx5-devel fcitx5 dbus-1-devel \
  rust cargo gcc-c++ make

Tuỳ chọn — Settings GUI (Qt6) + PNG icon:

Terminal 
sudo zypper install qt6-base-devel rsvg-convert
Ghi chú về Rust
Nếu rust/cargo từ repo distro quá cũ (Rust ≥ 1.70 được khuyến nghị), cài qua rustup:
Terminal 
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain stable
source "$HOME/.cargo/env"

2. Clone và build

Terminal 
git clone https://github.com/collyn/skey.git
cd skey
cmake -B build -DCMAKE_INSTALL_PREFIX=/usr -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
sudo cmake --install build
Mẹo
Nếu không cài qt6-base-dev, CMake sẽ tự động bỏ qua Settings GUI và chỉ build engine core + uinput server. Settings GUI không bắt buộc để sử dụng SKey.

3. Chạy setup

Sau khi build và install xong, chạy script cấu hình:

Terminal 
skey-setup

Script skey-setup sẽ tự động:

  1. Thêm SKey vào fcitx5 profile làm bộ gõ mặc định
  2. Bật ActiveByDefault=True và ShareInputState=All
  3. Export biến môi trường (GTK_IM_MODULE, QT_IM_MODULE, XMODIFIERS...)
  4. Khởi động lại fcitx5 daemon
  5. Trên Wayland: tự động reconnect compositor virtual keyboard
  6. Enable và start uinput server service

Cấu hình Fcitx5

Sau khi cài đặt, skey-setup tự động cấu hình hầu hết mọi thứ. Phần này hướng dẫn thêm cho từng trường hợp X11 và Wayland.

Trên X11

Trên X11, SKey hoạt động ngay sau khi cài đặt mà không cần cấu hình thêm. Script skey-setup tự động:

  • Export biến môi trường vào ~/.profile, ~/.xprofile, và shell config (.bashrc/.zshrc/config.fish)
  • Đặt GTK_IM_MODULE=fcitx, QT_IM_MODULE=fcitx5, XMODIFIERS=@im=fcitx
  • Khởi động fcitx5 daemon

Chuyển đổi bộ gõ bằng Ctrl+Space.

Mẹo
Nếu sau khi cài mà không gõ được tiếng Việt trên X11, hãy logout rồi login lại để session nhận biến môi trường mới. Hoặc chạy lại skey-setup.

Trên Wayland

Wayland yêu cầu thêm một bước: chọn Virtual Keyboard là Fcitx 5 trong System Settings. Cách làm tùy theo desktop environment:

KDE Plasma (Kubuntu, KDE Neon, Fedora KDE...)

  1. Mở System Settings
  2. Vào Input Devices → Virtual Keyboard
  3. Chọn Fcitx 5
  4. Bấm Apply
Quan trọng
Nếu không thấy tuỳ chọn Fcitx 5 trong danh sách Virtual Keyboard, hãy logout rồi login lại. Cần KDE Plasma ≥ 6.0 (hoặc KDE 5 + fcitx5-frontend-qt5).

GNOME (Ubuntu, Fedora Workstation, Zorin OS...)

  1. Mở Settings
  2. Vào Keyboard → Input Sources
  3. Bấm + để thêm nguồn nhập mới
  4. Chọn Vietnamese (Fcitx 5)
Ghi chú
Trên GNOME ≥ 45, Fcitx5 hoạt động qua giao thức zwp_input_method_v2 mặc định. Script skey-setup không đặt GTK_IM_MODULE trên GNOME/Wayland để tránh xung đột với GTK native text-input.

Hyprland / Sway / Niri (Tiling WM)

Thêm dòng sau vào file config của compositor:

Thêm vào ~/.config/hypr/hyprland.conf:

hyprland.conf 
exec-once = fcitx5 -d

Thêm vào ~/.config/sway/config:

sway/config 
exec fcitx5 -d

Thêm vào ~/.config/niri/config.kdl:

config.kdl 
spawn-at-startup "fcitx5" "-d"

So sánh X11 và Wayland

Đặc điểm X11 Wayland
Cấu hình thêm Không cần Chọn Virtual Keyboard
Biến môi trường Tự động qua skey-setup Tự động + environment.d
System tray icon XEmbed (classicui) StatusNotifierItem (SNI)
Chromium address bar Phát hiện qua AT-SPI2 Tự động qua CapabilityFlag::Url
Uinput delay 3–30ms (native), 6–60ms (Electron) 2–18ms (thấp hơn)
Sau khi fcitx5 restart Tự động reconnect Cần re-trigger virtual keyboard (skey-setup làm tự động)

Kiểm tra biến môi trường

Để kiểm tra biến môi trường đã được đặt đúng chưa:

Terminal 
echo $GTK_IM_MODULE     # Kết quả: fcitx
echo $QT_IM_MODULE      # Kết quả: fcitx5
echo $XMODIFIERS         # Kết quả: @im=fcitx

Nếu kết quả trống, chạy lại skey-setup rồi logout/login.

Cập nhật SKey

Có hai cách để cập nhật SKey lên phiên bản mới nhất:

Cách 1: Từ Settings GUI (dễ nhất)

SKey có sẵn tính năng cập nhật ngay trong giao diện — không cần mở terminal:

  1. Mở fcitx5-skey-settings (từ menu ứng dụng hoặc gõ fcitx5-skey-settings trong terminal)
  2. Chuyển sang Tab Info
  3. Bấm nút "Kiểm tra cập nhật" — ứng dụng sẽ truy vấn GitHub Releases để so sánh phiên bản
  4. Nếu có phiên bản mới: hiện dialog với version + release notes → bấm "Cập nhật ngay"
  5. Ứng dụng tự động: tải package → cài đặt (yêu cầu mật khẩu admin) → chạy skey-setup → restart Fcitx5
  6. Settings GUI tự khởi động lại với phiên bản mới
Mẹo
Toàn bộ quy trình chỉ cần bấm 2 nút: "Kiểm tra cập nhật" → "Cập nhật ngay". Sau khi cập nhật, bộ gõ sẵn sàng sử dụng ngay.

Cách 2: Từ Terminal

Nếu bạn cài qua repository (khuyến nghị), chạy lệnh cập nhật tương ứng:

Terminal 
sudo apt update && sudo apt upgrade fcitx5-skey
Terminal 
sudo dnf update fcitx5-skey
Terminal 
sudo pacman -Syu fcitx5-skey
Terminal 
sudo zypper up fcitx5-skey
Sau khi cập nhật
Nếu gặp lỗi (không gõ được, mất biểu tượng...) sau khi update, chạy lại:
Terminal 
skey-setup
Trên Wayland, kiểm tra lại Virtual Keyboard vẫn đang chọn Fcitx 5.

Khắc phục sự cố

Không gõ được tiếng Việt

Đây là vấn đề phổ biến nhất. Hãy thử các bước sau theo thứ tự:

  1. Chạy lại skey-setup:
    Terminal 
    skey-setup
  2. Logout rồi login lại để session nhận biến môi trường mới
  3. Trên Wayland: Kiểm tra Virtual Keyboard đã chọn Fcitx 5 chưa (xem Cấu hình Fcitx5)
  4. Kiểm tra fcitx5 đang chạy:
    Terminal 
    pidof fcitx5
    Nếu không có kết quả (fcitx5 không chạy), khởi động bằng: fcitx5 -d

Kiểm tra Uinput Server

Nếu chế độ Uinput không hoạt động (mất chữ trong terminal):

Terminal 
systemctl status fcitx5-skey-uinput-server@$USER.service

Nếu service không chạy, bật thủ công:

Terminal 
sudo systemctl enable --now fcitx5-skey-uinput-server@$USER.service

Xem log debug

SKey ghi log ra /tmp/skey.log. Theo dõi realtime:

Terminal 
tail -f /tmp/skey.log

Restart Fcitx5

Nếu cần restart fcitx5 thủ công:

Terminal 
fcitx5 -r -d

Hoặc sử dụng nút "Restart Fcitx5" trong fcitx5-skey-settings → Tab Info.

Sử dụng cơ bản

Sau khi cài đặt, chuyển đổi bộ gõ bằng Ctrl+Space. SKey hỗ trợ hai phương thức gõ:

Bảng gõ Telex

Tất cả transform hoạt động ở mọi vị trí trong từ (đầu, giữa, cuối):

Gõ Kết quả Mô tả
aa â Dấu mũ
oo ô Dấu mũ
ee ê Dấu mũ
uw / ww ư Dấu móc
ow ơ Dấu móc
aw ă Dấu trăng
dd đ D đét
s dấu sắc á, é, ó...
f dấu huyền à, è, ò...
r dấu hỏi ả, ẻ, ỏ...
x dấu ngã ã, ẽ, õ...
j dấu nặng ạ, ẹ, ọ...
z xóa dấu bỏ dấu thanh

Bảng gõ VNI

Gõ Kết quả Gõ Kết quả
1 dấu sắc 6 dấu mũ (â, ê, ô)
2 dấu huyền 7 dấu móc (ơ, ư)
3 dấu hỏi 8 dấu trăng (ă)
4 dấu ngã 9 d đét (đ)
5 dấu nặng 0 xóa dấu
